# Promotion checklist

## Starstruck path (need 16 stars on one repo)

Best targets: `collab-kit` or `shipkit`.

### Channels
1. **Reddit** (one post per sub, stagger 24h): r/commandline, r/node, r/opensource
2. **X / LinkedIn**: short demo + npx one-liner
3. **awesome lists**: keep PRs open (awesome-cli-apps)
4. **HN Show HN**: when account restriction lifts — use `docs/show-hn.md`
5. **Dev.to**: "Day 1 scaffolding + day 30 shipping" post pairing collab-kit + shipkit

### Sample Reddit title
Ship OSS releases without forgetting the checklist (changelog, tag, GitHub release, npm)

### Sample body
I kept skipping steps on small CLI releases, so I built shipkit:

```bash
npx @topdaily-dev/shipkit preflight
npx @topdaily-dev/shipkit ship --patch --yes
```

Pairs with collab-kit for repo scaffolding on day 1.

Repo: https://github.com/topdaily-dev/shipkit
npm: https://www.npmjs.com/package/@topdaily-dev/shipkit

Feedback welcome on missing release steps.

## Public Sponsor (manual)
1. Open https://github.com/sponsors
2. Sponsor any active maintainer ($1+/month is enough)
3. Ensure sponsorship is public
4. Badge appears on your profile (can take a day)
