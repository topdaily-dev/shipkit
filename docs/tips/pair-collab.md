# Pair with collab-kit

Scaffold with collab-kit on day 1, ship with shipkit on day 30.

```bash
npx @korykaai/collab-kit init . --oss-toolchain
collab-kit enable-hooks .
npx @topdaily-dev/shipkit preflight
npx @topdaily-dev/shipkit ship --patch --yes
```

Human co-authors only — see [collab-kit pair-programming](https://github.com/kory-kaai/collab-kit/blob/main/docs/pair-programming.md).
